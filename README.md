# Punktezettel

Doppelkopf-Punktezettel als WebApp (und PWA) — läuft komplett offline, ohne Konto und ohne Server. Alle Daten bleiben im Browser.

## Features

- Spieler anlegen, Hände erfassen (Normal- und Solo-Spiele)
- Tabelle, Verlauf und Statistik
- Hell-/Dunkel-Design, Installation als App möglich
- Lokale Speicherung, Service Worker für Offline-Nutzung
